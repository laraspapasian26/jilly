# Image Gallery Usage

This image gallery allows users to easily upload and display images. Below are the instructions on how to use the gallery and add images.

## How to Use the Image Gallery
1. **Open the Gallery**: Navigate to the image gallery section of the application.
2. **Upload Images**: Click on the 'Upload' button to add images to the gallery.
3. **Display Images**: Once uploaded, the images will be displayed in a grid format.

## Adding Images
- To add images, use the upload form and select your image files.
- Supported formats include JPG, PNG, and GIF.
- After selection, confirm the upload to display the images in the gallery.

## Notes
- Make sure your images do not exceed the maximum file size limit.
- You can view and delete images directly from the gallery interface.

For further assistance, check the documentation or contact support.
